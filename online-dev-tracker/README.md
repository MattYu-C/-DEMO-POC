# 線上開發追蹤表

只記件數與數字，不放客戶姓名、帳號或聯絡方式。

## weekly_funnel.csv（每週一列，每平台一列）
漏斗：貼文 → 索取關鍵字 → 已發出 → 已看過 → 回覆 → 聊到需求 → 約視訊 → 成交。
- messages_sent 是「已發出」，不等於對方收到。要用 messages_seen（已看過）判斷送達。
- hours_spent 記當週投入線上開發的小時數。

## post_timing_log.csv（每則貼文一列，發文時段測試）
- group：A 或 B，對應不同發文時段。
- 每則發出滿 48 小時後記錄，讚數扣掉本人的讚，回覆扣掉本人的回覆。
- viral_flag：該則是否為爆文（Y/N），分析時單獨看，不混入中位數。
- 比較用中位數，每組至少 10 則才看方向。

## 發文時段測試設計（Matt 已同意，2026-11-27）
- 期間 4 到 6 週，一天一篇。
- 美業等：A = 21:00，B = 22:15，時段在星期幾之間輪替。
- 早餐店另外比：A = 15:15，B = 20:30（暫定），不與美業混算。
- 主題與行業平均分配到兩組；格式與行動呼籲維持一致。
